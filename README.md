# AI ProjectHub v2: AI Project Showcase Website

A scrapbook-style showcase site where college students browse 30 AI projects, pick the work they need, see the price live, and send the order to your WhatsApp.

**Stack:** React 19, Tailwind CSS 4, Framer Motion, Lucide icons, Express (Node.js) API and a JSON file database.

## Run it (simplest)

You need **Node.js 18 or newer** from https://nodejs.org. Open a terminal in this folder and run:

```bash
npm install
npm start
```

- Website: http://localhost:3000
- Admin: http://localhost:3000/admin-side-data (login `admin@gmail.com` / `123456`)

The `dist/` folder already contains the built website, so `npm start` works straight away.

## If you change the design or code

```bash
npm run dev      # live-reload while editing  →  open http://localhost:5173
npm run build    # rebuild dist/ when you're done, then npm start
```

## Admin panel

- **Projects:** add, edit, hide or delete projects. Each project has a cover photo (upload one or paste a link), a tagline, a witty one-liner, features, real-world uses and tech stack.
- **Work & payment items:** inside each project, add or remove items (PPT, research paper and so on) and set their prices. Ticked items are pre-selected for the student.
- **Payment & settings:** set the WhatsApp number, UPI ID and payment terms (shown on the receipt card). You can also add **testimonials**. The testimonial section only appears on the site after you add at least one real review.

## Photos

The 30 projects use free Unsplash photo links. If a link ever stops working, the card shows a clean placeholder instead of a broken image. For the best look, upload your own screenshots or project photos from the admin panel. They are saved in `data/uploads/`.

## Going live

Push the folder to GitHub, then create a Web Service on Render or Railway:
- Build command: `npm install && npm run build`
- Start command: `npm start`
- Environment variables: `ADMIN_EMAIL`, `ADMIN_PASSWORD` (**change the password!**)

Free hosting plans wipe files when the app redeploys, which deletes your admin edits and uploaded photos. To keep them, add a persistent disk or volume and set `DATA_DIR` to its path, for example `/var/data`.
